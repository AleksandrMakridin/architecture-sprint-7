## 1. Управление доступом
**Многофакторная аутентификация (MFA)**: Критически важный фактор для защиты доступа к системам.

**Аудит учётных записей**: Нужен регулярный пересмотр учётных записей с повышенными привилегиями.

**Принцип минимальных привилегий**: Обеспечивает ограничение доступа только к необходимым данным.

**Журналирование операций доступа**: Необходимо для отслеживания и анализа инцидентов доступа к данным (для ИБ).
## 2. Безопасность данных
**Классификация данных**: Политика классификации данных должна быть актуальной и соответствовать законодательству.

**Шифрование данных**: Пункт нужен т.к. у нас есть КТ (коммерческая тайна) и Перс Данные. 

**Резервное копирование и восстановление**: Плановая проверка ПАВ (план аварийного восстановления) не реже 1-го раза в год.
## 3. Защита инфраструктуры
**Межсетевой экран**: Ограничение входящего и исходящего трафика.

**Сегментация сети**: Ограничение доступа на основе логические зон.

**Сканирование уязвимостей**: Регулярное внутреннее и внешнее сканирование для выявления и устранения уязвимостей.
## 4. Управление инцидентами
**Система мониторинга безопасности (SIEM)**: Для корреляции событий и анализа аномалий.

## 5. Специфические аспекты
**Управление мобильными устройствами (MDM)**: Контроль доступа к корпоративным данным на мобильных устройствах.

**VPN и шифрование**: Для безопасного удалённого доступа к ресурсам.

## Обоснование выбора

**Аудит безопасности**: Включение всех вышеуказанных разделов обеспечит комплексный подход к подготовке к аудиту безопасности.
